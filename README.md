# Sales Data Analysis Project

## Project Overview
This beginner-friendly portfolio project analyses a fictional retail sales dataset using Microsoft Excel and MySQL. It explores order volume, revenue, units sold, city-wise performance, category-wise performance and salesperson contribution.

## Tools
- Microsoft Excel
- MySQL / MySQL Workbench
- CSV

## Files
- `Sales_Data_Analysis_Completed.xlsx` — raw data, calculated sales, KPI formulas, summary tables and charts.
- `sales_data.csv` — dataset for importing into MySQL or using in other tools.
- `Sales_Analysis_SQL.sql` — database/table setup and 10 analysis queries.

## Excel Work
- Calculated total sales using Quantity × Unit Price.
- Summarised total orders, revenue, units sold, average order value and highest order value.
- Compared revenue by city and product category.
- Created charts to present the summaries.

## SQL Work
- Created a database and sales table with a primary key and basic validation.
- Wrote queries using `COUNT`, `SUM`, `AVG`, `GROUP BY`, `ORDER BY`, `DATE_FORMAT` and `LIMIT`.

## Dataset Note
All customer names and transactions are fictional and created for learning and portfolio practice.

## How to Use
1. Open the Excel workbook and review `Read_Me`, `Raw_Data`, `Cleaned_Data` and `Summary`.
2. In MySQL Workbench, open `Sales_Analysis_SQL.sql` and execute the setup statements.
3. Import `sales_data.csv` into the `sales` table using the Table Data Import Wizard.
4. Run the analysis queries in the SQL file.

## Skills Demonstrated
Excel formulas, data organisation, calculated columns, KPI reporting, summary tables, charts, SQL table creation, filtering, aggregation and grouping.
